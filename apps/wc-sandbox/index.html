Not graded. The React page labels every specimen with how far its contract got, because someone drove each one in a browser. Nothing here claims that.

Button

Three axes become three attributes on the host, and the theme selects them with :host([hierarchy='primary']). The other three backends invented a data-ds-<axis> family to do this; a shadow root makes it unnecessary, because the host's own attributes are already scoped by its tag.

Checkbox

A state with three values rather than two. The host carries checked="mixed" for CSS and the inner element carries aria-checked="mixed" for assistive technology — one fact in two places, which is what the shadow boundary costs.

TextField

The DOM's own input event, as in Vue and Angular. The host is not a form control: it does not participate in a form and does not carry the value. That is a real gap, recorded rather than solved.

Tabs + TabItem + TabPanel

A member finds its collection with closest() — the DOM answering a question React, Vue and Angular each answered with a container of their own, and the only one of the four that works across a framework boundary.

Overview Activity Settings A collection with two kinds of member. This panel and its tab compare against the same value; neither holds it. Selection follows focus in this pattern, which suits panels already in memory and is the wrong default for one that fetches. The contract cannot say which was chosen. A panel for the disabled tab, so the tab's aria-controls has something to name.

Dialog

A native <dialog> inside the shadow root. The platform supplies focus containment, inertness and Escape to an element it owns, wherever that element lives — no effect, no watcher, no change detection, just a method call in #update().

Switch

control: shared costs three React props, one Vue defineModel, one Angular model() — and here three mechanisms: an attribute, a property, and a ds-checked-change event. Closest in shape to React, and unlike React each of the three does a genuinely different job.

Accordion + AccordionItem

cardinality: many, so the selection is a list. An attribute is a string, so this is the one backend that had to choose a separator — space-separated, like every other token list the platform already has.

What is a contract? The agnostic specification a component is generated from. It is the thing this library ships; the component is output. Why does this one open? Because the contract says what opening means: the accordion holds a selection, this item is a member of it, and the trigger toggles that membership. Tooltip

Correct structure, and nothing opens it — as in all three other backends. A gap in the CONTRACT reproducing identically in a fourth is as close to proof as this repo gets that it is not an emitter's fault.

A contract can describe this bubble. It cannot yet say what opens it, or where it goes.

Field

THE ONE THING THIS BACKEND CANNOT DO. A Field's control is named by its label and described by its description, and those relationships are IDREFs. An IDREF resolves within one tree, and the control a consumer slots in lives in a different one — so the reference points at nothing. See the research note; the platform answer is the ARIA reflection API, which is not in every browser yet.
